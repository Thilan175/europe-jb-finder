EUROPE JOB FINDER – SRI LANKA
1. Extract the ZIP file.
2. Double-click index.html to open it in Chrome, Edge or Firefox.
3. Use the official SLBFE links on the right to check current vacancies.
4. Add only real advertisements you have checked. Keep unverified ads as "Check needed".
5. Export a JSON backup regularly. Data is stored only in the browser on this computer.

Important:
- This starter dashboard does not automatically scrape SLBFE, Facebook or job boards.
- It does not itself verify an agency or job order. Verify directly through SLBFE.
- Do not pay fees or hand over documents based only on social-media posts.
- For a hosted multi-device website with automated feeds, a server/database and approved integrations are required.
